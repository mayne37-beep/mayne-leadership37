Chapter 1

WHAT IS A SYSTEM?

Start at the lowest level: parts, connections, purpose, and boundary.

Foundation

Linear thinking looks for a cause. Systems thinking looks for a structure.

B

Linear thinking can be useful for simple problems. It becomes risky when causes interact, accumulate, feed back, or arrive after delays.

Core shift: Ask “What caused this?” when the problem is simple. Ask “What relationships are producing this behavior over time?” when the problem is systemic.

WHY FIXES CAN MAKE THINGS WORSE

Recurring structures create familiar traps—and reveal leverage.

System Archetypes

Fixes That Fail

Short-term relief can create delayed harm.

Overtime
Output ↑
Relief
Delayed consequence: fatigue → errors → rework → backlog. The fix is attractive because relief arrives before the harm.
Shifting the Burden

Symptom relief can reduce pressure to build the deeper capability.

Symptomatic path

Overtime / quotas

Fast relief, but dependence grows.

Fundamental path

Capability + process improvement

Slower relief, but structural improvement.
Warning sign: the more the organization relies on the quick-relief path, the less urgency it feels to strengthen the fundamental solution.
Limits to Growth

Success can expose the constraint that eventually slows success.

Growth engine

Better tools or staffing increase throughput.

Limiting condition

Supervisor capacity, approvals, training load, or quality review becomes dominant.

Leverage question: What constraint must be relieved for improvement to continue?
