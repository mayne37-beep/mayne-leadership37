Video export and compatibility

Rendering uses your own browser, not a remote AI service. MP4 output is available only if the browser supports MP4 recording; otherwise an actual WebM video is created. About Mayne Leadership Video Studio

The studio includes a home dashboard, reusable templates, focused editing panels, and a local-first video renderer. Start with the included Task vs. Relationship sample, write a script for each scene, select a design, and set its duration.

Voice preview uses your browser's built-in speech engine. To hear narration in an exported video, upload an audio recording for each scene. The five included characters load automatically on every device, and their outfit selections are included in JSON backups. Audio, uploaded presenter photos and custom imported character packs are stored on this device using IndexedDB and are not included in JSON backups.

Important: Illustrated presenters are static stylized visuals, not talking AI avatars. Realistic photo presenters can be uploaded; AI narration and talking-video generation require the server-side provider integrations to be configured. Generated talking-avatar clips can be downloaded and then imported into individual scenes for video compositing.
