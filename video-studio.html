Video export and compatibility

Rendering uses your own browser, not a remote AI service. MP4 output is available only if the browser supports MP4 recording; otherwise an actual WebM video is created. Keep this tab visible while rendering. Video export may not be supported by all browsers, and very long projects may use significant memory. AI avatars, natural AI voice generation, cloud projects, and lip synchronization are planned integrations, not Phase 1 features.

About Mayne Leadership Video Studio

This first release is an editable, local-first video storyboard and renderer. Start with the included Task vs. Relationship sample, write a script for each scene, select a design, and set its duration.

Voice preview uses your browser's built-in speech engine. To hear narration in an exported video, upload an audio recording for each scene. Audio is stored on this device using IndexedDB and is not included in JSON backups.

Important: Illustrated presenters are static stylized visuals, not talking AI avatars. High-quality voice synthesis and photorealistic avatar generation require a separate AI integration.
