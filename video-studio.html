Video export and compatibility

Rendering uses your own browser, not a remote AI service. MP4 output is available only if the browser supports MP4 recording; otherwise an actual WebM video is created. Keep this tab visible while rendering. Video export may not be supported by all browsers, and very long projects may use significant memory. Real presenter photos and scene timeline are included. ElevenLabs voice and HeyGen video generation work only after server-side provider keys are configured. Generated HeyGen clips are downloadable separately, not yet overlaid into the local storyboard render. Cloud projects and local AI lip-sync are not included.

About Mayne Leadership Video Studio

The studio is an editable, local-first video storyboard and renderer. Start with the included Task vs. Relationship sample, write a script for each scene, select a design, and set its duration.

Voice preview uses your browser's built-in speech engine. To hear narration in an exported video, upload an audio recording for each scene. Audio and presenter photos are stored on this device using IndexedDB and are not included in JSON backups.

Important: Illustrated presenters are static stylized visuals, not talking AI avatars. Realistic photo presenters can be uploaded; AI narration and talking-video generation require the server-side provider integrations to be configured. Generated talking-avatar clips are separate downloads, not automatically composited into this storyboard.
