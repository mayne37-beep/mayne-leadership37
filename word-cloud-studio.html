    Using Classroom Response Studio

    Start with a blank slide. Open the pencil tool to choose a question type and write your question. Open the speech bubble to enter responses. Repeated words become larger; multiword phrases stay together.

    Choose your look. The sparkle opens themes. The paint tool lets you change the background, heading, word colors, font, images, and cloud layout. The panel closes with its × button or by clicking its selected tool.

    Control the reveal. Choose instant responses, responses on click, or private responses in Edit or Interaction. “Reveal responses” shows everything received so far. Private responses are available in View results, and stay off the slide.

    Present. Start presentation for a clean, full-screen slide. For a second monitor, use the arrow beside it and open the projector window; move that window onto your display. Changes in this editor update that projector window.

    Collect live student responses. Add a question, then select Start live session to generate a QR code and student link. Students respond from their own phones or computers without signing in. In Live session, choose Instructor-paced to keep students on your slide or Self-paced to let them use Previous and Next. You can switch during a session using the same QR code. Responses update automatically. Pause or end a session in Live session; use Clear results to let students respond again using the same link. Each session expires after seven days.

    Teacher controls. Keep this teacher tab open while presenting. Its session key is saved only in this browser and is never included in student links or exported copies. Reopen this page in the same browser to resume managing a session.

    Local entry. The speech bubble still lets you enter individual responses or paste one participant per line on this computer.

    Manage slides. Use the Slides sidebar to add, duplicate, or remove the selected slide. Drag a preview or use the up and down arrows to change the order.

    Keep your work. Your draft autosaves in this browser. To use your projects on another computer, open My Projects, sign in, and select Save to website. Open My Projects on the other computer and sign in with the same account. Use Copy browser projects to move saved projects from this browser to the website. Save class results keeps student responses in this browser. Import and export let you work with portable backups.

    Keyboard shortcuts

    • P start presentation · Esc exit or close a panel
    • ← / → previous / next slide during presentation
    • R reveal / hide results · F full screen
    • Ctrl / ⌘ + S save an HTML copy

    No student account or installation is required. Live responses need an internet connection. Blank slides intentionally have no message in the middle.
