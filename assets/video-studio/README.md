# Included Video Studio characters

Amara, Daniel, Sofia, Kenji, and Priya each have professional and casual outfits.
These ten transparent PNGs are permanent same-origin website assets, available
without an import or browser media database. The build copies this directory into
the deployed `public/assets` tree along with the existing website assets.

Source: `Mayne_Leadership_Character_Library_Ready_To_Import.zip`, supplied by the
site owner. The PNG bytes and source manifest are preserved unchanged. According
to the supplied manifest, these are AI-generated fictional characters; no real
person likeness was used and no identity or voice is implied.

The curated catalog and stable outfit IDs are in
`assets/video-studio-library-core.js`. Project JSON and local render manifests
preserve included outfit selections. Uploaded photos, narration, video clips,
and custom imported character packs retain their existing device storage behavior.
